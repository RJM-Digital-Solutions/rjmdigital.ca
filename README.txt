- images/ folder

How to upload to GitHub:
1. Open your GitHub repository.
2. Click Add file > Upload files.
3. Drag every file and folder from this package into GitHub.
4. Click Commit changes.
5. Go to Settings > Pages.
6. Under Source, choose Deploy from a branch.
7. Choose main and /root, then Save.

Important:
- Keep the folder structure the same.
- index.html must stay in the main/root folder.
- The images folder, css folder, and js folder must stay named exactly the same.

Contact form:
The form uses a free mailto setup. When someone submits, it opens their email app and creates an email to info@rjmdigital.ca.
For a more professional form later, you can connect Formspree, EmailJS, or Netlify Forms.
